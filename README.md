# Helios V1

Desarrollo de un Multímetro Digital Virtual para la Medición de Tensión, Corriente y Potencia de un Panel Fotovoltaico Mediante Arduino y MATLAB.

## 📋 Descripción
Este proyecto permite realizar mediciones de parámetros eléctricos (tensión, corriente y potencia) en sistemas fotovoltaicos mediante un circuito con Arduino y una interfaz virtual desarrollada en MATLAB App Designer.

## 📁 Archivos del Repositorio
* `HeliosV1.ino`: Código fuente para la placa Arduino.
* `HeliosV1.mlapp`: Aplicación interactiva de MATLAB App Designer.
* Archivos de audio (`.mp3`, `.wav`): Recursos sonoros utilizados por la interfaz de MATLAB.

## 🛠️ Requisitos
* **Arduino IDE** (para cargar el código a la placa).
* **MATLAB** con App Designer e instalación de soporte para Arduino (si aplica).

## 🚀 Instrucciones de uso
1. Carga el programa `HeliosV1.ino` en tu placa Arduino usando Arduino IDE.
2. Abre MATLAB y ejecuta la aplicación `HeliosV1.mlapp`.
3. Asegúrate de tener los archivos de audio en la misma carpeta del proyecto para su correcto funcionamiento.
4. Actualiza las direcciones de audio para reproducirlos
